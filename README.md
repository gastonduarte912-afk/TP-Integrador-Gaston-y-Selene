# Descripción

Este proyecto consiste en un sistema de gestión de países desarrollado en Python.

El programa permite administrar información de distintos países utilizando listas, diccionarios, funciones, estructuras repetitivas y condicionales.

El sistema funciona mediante un menú interactivo en consola.

---

# Funcionalidades

El programa permite:

- Agregar países
- Mostrar países cargados
- Buscar países por nombre
- Actualizar población y superficie
- Filtrar países por continente
- Filtrar países por rango de población
- Filtrar países por rango de superficie
- Ordenar países por nombre
- Ordenar países por población
- Ordenar países por superficie
- Mostrar estadísticas generales


# Estructuras utilizadas

## Listas

Se utiliza una lista principal llamada `paises` para almacenar todos los registros.

## Diccionarios

Cada país se representa mediante un diccionario con las siguientes claves:

- nombre
- poblacion
- superficie
- continente

## Funciones

El programa está modularizado mediante funciones para organizar mejor las responsabilidades del sistema.
